# backend – REST API

Chưa chọn công nghệ. Khi bắt đầu cần có:

- `Dockerfile` – lắng nghe cổng `8080`
- Đọc cấu hình từ biến môi trường: `DATABASE_URL`, `AI_ENGINE_URL`, `JWT_SECRET`
- Endpoint đăng nhập / đăng ký (bắt buộc vì app có dữ liệu online)
- Bỏ comment service `backend` trong `docker-compose.yml`
